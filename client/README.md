# Finapp React Front-End Client

A front-end client for financial application project made with TypeScript, React and Chart.js

## Chart Implementation

Using the Chart.js library with react-chartjs-2.
Click on links for more info:

- [Charts.js](https://www.chartjs.org/) - Simple yet flexible JavaScript charting library for the modern web
- [react-chartjs-2](https://react-chartjs-2.js.org/) - React components for Chart.js
